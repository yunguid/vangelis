# Opening piano samples

Versilian Studios Community Edition (VSCO 2 CE), Upright Nr1, soft (pp),
round-robin 1. CC0-1.0. Nine recordings span C2 to C6, with G samples
between C anchors so notes are shifted by at most four semitones.

Upstream: https://github.com/sgossner/VSCO-2-CE/tree/440300901dfe9275fd84e0b7763af1f8443ae62e/Keys/Upright%20Nr1

Source names: `UR1_{C2,G2,C3,G3,C4,G4,C5,G5,C6}_pp_RR1.wav`.
These were already present in this project's former starter-pack library.
Converted with ffmpeg/libmp3lame quality 3, retaining stereo and sample rate;
each source is peak-normalized to -6 dBFS before encoding. No compression
or noise removal is applied to the recordings. Playback is a live instrument,
not a recording of the song.
